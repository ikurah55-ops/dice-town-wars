# Steamストアページ 素材チェックリスト

> 素材の作成は、**ストアページの内容と体験版が固まってから**始める（それまでは作らない）。

## 画像素材

ストアページに必須の画像は、4種類のカプセルとスクリーンショット5枚以上。
カプセルは1枚のキーアートから切り出すと統一感が出る（Steamの公式テンプレートあり）。

| 完了 | 素材 | サイズ(px) | 必須 | 使われる場所・注意点 |
|---|---|---|---|---|
| [ ] | ヘッダーカプセル | 920×430 | 必須 | ストアページ上部、おすすめ欄。文字はタイトルのみ |
| [ ] | スモールカプセル | 462×174 | 必須 | 検索結果・一覧。ロゴがほぼ全面を占めるように |
| [ ] | メインカプセル | 1232×706 | 必須 | トップページのカルーセル |
| [ ] | 縦長カプセル | 748×896 | 必須 | セール時のトップ・セールページ |
| [ ] | スクリーンショット | 1920×1080以上（16:9） | 必須・5枚以上 | 実プレイ画面のみ。4枚以上に「全年齢向け」を付ける |
| [ ] | ページ背景 | 1438×810 | 任意 | 未設定ならスクショから自動生成 |
| [ ] | ライブラリ用画像（カプセル・ヒーロー・ロゴ） | 別ページ参照 | 発売前まで | Steamライブラリ表示用。近日登場ページの段階では後回し可 |

スクリーンショット候補：
- サイコロを振る瞬間
- 建物カードの発動
- ショップ（カード購入）画面
- CPU対戦の盤面
- ラン進行マップ（ストーリーのマップ）

## 動画素材

トレーラーは必須ではないが、ウィッシュリスト獲得に最も効く。
公式 Next Fest トレーラーの収録候補になるには、**1月18日まで**にストアページへ載せておく必要がある。

| 完了 | 素材 | 長さ・仕様の目安 | 優先度 | 内容・注意点 |
|---|---|---|---|---|
| [ ] | メイントレーラー | 30〜60秒、1920×1080・16:9・MP4 | 最優先 | 最初の5秒で「サイコロ→カード発動→コンボ」を見せる。ロゴは冒頭か最後に短く |
| [ ] | ゲームプレイ動画 | 1〜2分 | 推奨 | 編集控えめで1ターン〜数ターンを通して見せる |
| [ ] | 体験版告知トレーラー | 15〜30秒 | 任意 | 既存トレーラーの差し替え。「体験版配信中」は動画内で表示 |
| [ ] | X用ショート動画・GIF | 5〜15秒、縦長または正方形も | 推奨 | 宣伝用Xアカウントで使う。コンボの気持ちよさが伝わる一瞬を切り出す |
| [ ] | Next Fest配信用の素材 | 配信画面のオーバーレイ等 | 任意 | フェス期間中にライブ配信する場合のみ |

動画の仕様は目安。アップロード前にSteamのトレーラー公式ガイドで最新の要件を確認する。

## テキスト・設定項目

海外の売上を狙うなら、日本語と英語の両方で用意する。

- [ ] ゲーム名（日本語・英語）：サイコロシアム / Dicolosseum（決定済み。ストア登録時に確認）
- [ ] 短い説明文：カプセル横に出る1〜2文
- [ ] 詳細説明：特徴、遊び方、売りになる点。見出しと画像・GIFを交えて構成する
- [ ] タグ：デッキ構築、ローグライク、ダイス、ストラテジー、ターン制など
- [ ] ジャンル・カテゴリ（シングルプレイヤーなど）
- [ ] 対応言語（UI・字幕・音声それぞれ）
